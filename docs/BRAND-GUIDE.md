# Brington branding

## Assets and logo

The original supplied branding reference is retained in `assets/source/Logo Design.png`. The current website serves a copy from `public/images/brington-branding.png`. The full reference is not a final emblem-only logo: the brief identifies the upper BG emblem as the logo. Obtain an approved isolated emblem before final brand sign-off. Preserve its proportions and give it clear space.

## Intended palette

- Deep navy: #002A54 / #002B57, primary corporate colour.
- Gold: #C68A00 / #D39A19, restrained accents and interactive details.
- Silver and charcoal: technical supporting tones.
- White and off-white: content backgrounds.

The existing stylesheet remains the source for the current implementation; this structural change does not redesign its palette.

## Typography, components and spacing

The current design uses DM Sans for body text and Space Grotesk for headings, loaded through Google Fonts. Keep strong heading hierarchy, readable body copy and generous section spacing. Buttons should have clear action labels, cards consistent spacing, and keyboard focus visible. Icons must have accompanying text. Keep navy dominant when extending the design and use gold sparingly.

## Imagery direction

Use construction, PPE, inspections and engineering imagery. The current CSS uses remote Unsplash imagery. Future owner-provided images should be stored as originals in `assets/source` and optimized web copies in `public/images`. Avoid implying stock imagery depicts actual clients or completed work.
